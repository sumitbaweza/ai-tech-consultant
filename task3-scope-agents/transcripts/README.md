# Transcripts

> **Stand-ins.** These three transcripts were written by hand to build and test the scope team. The brief asks for at least three recorded role-play meetings with a friend, one of them a follow-up that changes the first. The recorded transcripts replace these files, and these stay only as test material.

| File | Meeting | Format | What it exercises |
| --- | --- | --- | --- |
| `01-first-meeting-bright-smile.txt` | Bright Smile Dental Network, first meeting | `[hh:mm:ss] Name: text` | A vague request ("make the search better"), requests an existing setting may cover (member approval, review moderation, map on search results), a conflict (two vs three membership levels), a nice-to-have, a deadline and a budget |
| `02-first-meeting-zen-yoga.txt` | Zen Yoga Collective, a second client | `Name (hh:mm:ss): text` | A clearly custom integration (booking synced to MindBody), events and classifieds, a different transcript format |
| `03-followup-bright-smile.txt` | Bright Smile, follow-up to meeting 1 | `[hh:mm:ss] Name: text` | Scope v2: a changed item (three membership levels, insurance filter), a removed item (the blog), a new out-of-scope item (online booking with Dentrix, a change order), unchanged items (the map, the import) |

Run meeting 1 first, approve its scope, then add meeting 3 to the same project: the team treats it as a follow-up and compares it with the approved v1.

## Formats the splitter reads

`[00:01:23] Name: text`, `00:01:23 Name: text`, `Name (00:01:23): text`, `Name: text`, and WebVTT cues (`00:01:23.000 --> 00:01:27.000`, then `Name: text`). A line that matches none of them continues the previous speaker's turn. Google Meet and Zoom exports fit one of these.
